# 배경지식

# 1. RNN

순환 신경망이라고 한다.

현재 처리하는 $h_t$(hidden state)에 $h_{t-1}$을 이용하여 이전 정보를 포함하는 것.

$h_t = \rm{tanh}\it(W_xx_t+W_hh_{t-1}+b)$
$W_x$ : 입력층 가중치, $x_t$ : 입력(현재 단어), $W_h$ :이전 타임스텝 가중치

# 2. 인코더와 디코더

### 1) 인코더

입력 시퀀스를 처리하여 그 안에 담긴 정보를 은닉 상태 등의 형태로 표현한다. 기본적인 Encoder-Decoder에서는 마지막 은닉 상태를 이용해 
입력 시퀀스의 정보를 디코더에 전달할 수 있다.

### 2) 디코더

인코더가 전달한 정보와 이전 디코더의 상태 및 입력 토큰을 이용하여 새로운 시퀀스를 생성한다. 번역에서는 이를 이용해 번역문을 단어 단위로 생성한다.

### 3) RNN기반 인코더와 디코더의 학습 과정

1. 인코더가 입력 시퀀스를 처리하여 정보를 표현한다.
2. 디코더가 인코더의 정보와 이전 디코더의 상태 및 입력 토큰을 이용해 다음 단어를 예측한다.
    - 디코더는 처음에 <SOS>토큰을 입력받아서 첫 단어를 예측함.
3. 예측 결과와 정답을 비교하여 손실을 계산한다.
4. 역전파를 통해 손실을 줄이는 방향으로 인코더와 디코더의 학습 파라미터를 업데이트한다.

# 3. Attention

### 1) 등장배경

RNN같은 Seq2Seq 기반의 인코더-디코더에서, 디코더가 시퀀스 초반의 정보를 제대로 이용하지 못함.
이를 해결하기 위해 디코더가 인코더의 모든 $h_t$에 접근하도록 만듦.

### 2) 아이디어

디코더에서 단어를 예측하는 매 시점마다 인코더의 전체 h_t를 참고함. 이때 현재 예측해야 할 단어와 연관이 있는 부분에 가중치를 주어 참고

### 3) 어텐션 함수

**Attention(Q, K, V) = Attention Value**

어텐션 함수는 주어진 '쿼리(Query)'에 대해서 모든 '키(Key)'와의 유사도를 각각 구함
구해낸 이 유사도를 키와 맵핑되어있는 각각의 '값(Value)'에 반영
유사도가 반영된 '값(Value)'을 모두 더해서 리턴 ⇒ Attention Value

seq2seq + 어텐션 모델에서 각각의 Q, K, V

<aside>

Q = Query : t 시점의 디코더 셀에서의 은닉 상태
K = Keys : 모든 시점의 인코더 셀의 은닉 상태들
V = Values : 모든 시점의 인코더 셀의 은닉 상태들

</aside>

### 3) 작동과정 - RNN 인코더-디코더 기반

1. 인코더가 은닉 상태 $h_t$ 생성

2. 디코더의 현재 상태 $s_t$와 각각의 인코더 은닉 상태 $h_i \ (i=1,\ldots,n)$를 비교하여 어텐션 점수 계산
<br>어텐션 점수의 모음: $e^t = [\text{score}(s_t,h_1), \text{score}(s_t,h_2), \ldots, \text{score}(s_t,h_n)]$

3. 점수를 소프트맥스 함수로 변환하여 어텐션 가중치 계산. 이 분포를 어텐션 분포 $\alpha^t$라고 함
<br>$\alpha^t = \text{softmax}(e^t)$

4. 인코더의 은닉 상태들과 어텐션 가중치의 가중합을 계산. 이 값이 어텐션 값 $a_t$이며, 컨텍스트 벡터라고도 함
<br>$a_t = \sum_{i=1}^{n} \alpha_i^t h_i$

5. $s_t$와 $a_t$를 결합한 벡터에 가중치 행렬 $W_c$를 적용하여 어텐션 정보를 반영한 $\tilde{s}_t$ 생성
<br>$\tilde{s}_t = \tanh\left(W_c[s_t;a_t]+b_c\right)$

6. $\tilde{s}_t$를 출력층에 입력하여 최종 예측 확률 분포 생성
<br>$\hat{y}_t = \text{softmax}(W_y\tilde{s}_t+b_y)$

7. 예측 확률 분포에서 확률이 가장 높은 단어를 최종 예측 단어로 선택
